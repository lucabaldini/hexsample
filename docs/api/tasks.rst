:mod:`~hexsample.tasks` --- Tasks
=================================

This module provide all the high-level simulation and analysis tasks of the
package, each implemented as a single function with a precise signature, as
well as the default values for their arguments.

The available tasks cover the following operations:

* detector simulation;
* event reconstruction;
* pedestal, noise, gain, and response-equalization calibration;
* position-reconstruction calibration;
* generation and visualization of calibration products;
* event display and quick-look data analysis.

The complete API reference for all available tasks is provided below.
